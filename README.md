# PDF 编辑器 (PdfEditor) - 桌面专业版

一款基于 **Python + PySide6 (Qt 6) + PyMuPDF (fitz)** 构建的现代轻量、高性能、清爽美观的 Windows 桌面 PDF 编辑器。可独立编译打包为单个或便携式 `.exe` 文件，免安装运行。

---

## 🌟 核心特色功能

### 1. PDF 浏览与全生命周期编辑
- **连续高清矢量渲染**：基于 MuPDF 引擎，毫秒级多页渲染，清晰锐利无毛刺，支持 25%~500% 任意平滑缩放、整页适应与宽度适应。
- **页面自由旋转**：支持顺时针 90°、180°、270° 旋转单页或批量旋转。
- **页面插入与删除**：一键在任意位置插入 A4 空白页，或删除无用页面（自动防误删保护，至少保留 1 页）。
- **页面单页提取**：右键任意页面可一键将其单独提取导出为新的独立 PDF 文件。
- **批量文本水印**：支持设置水印文字、字号大小、透明度、旋转倾斜角，并可自由选择应用于全部页或指定页码。
- **PDF 体积压缩瘦身**：一键执行无损流压缩（`deflate=True`）与垃圾对象回收（`garbage=4`），大幅缩减 PDF 体积。

### 2. 任意页拖拽调整页码顺序
- **左侧缩略图直观排版**：左侧面板展示所有页面真实高清缩略图与页码标记。
- **鼠标拖拽自由排序**：直接用鼠标按住某页缩略图拖拽到目标位置释放，即时完成页面重排。
- **快捷上下移动按钮**：支持一键将当前页“向上移动”或“向下移动”。
- **批量序列重排**：提供专属重排对话框，支持输入完整序列（如 `3, 1, 2, 5, 4`）一键批量编排。

### 3. 任意页自由插入图片
- **可视化交互图层**：点击【插入图片】后选择本地图片（PNG、JPG、JPEG、BMP、WEBP 等），图片立即浮现在当前 PDF 页面上。
- **自由拖拽与八向锚点缩放**：鼠标按住图片中心可任意平移放置，拉动 8 个边角控制把手可等比例放缩。
- **一键固化烧录**：调整完毕后点击工具栏【固化图片】，系统自动将其精确换算为 PDF 物理点数坐标并永久写入 PDF 页面。

### 4. 多 PDF 文件批量合并
- **可视化合并管理器**：独立的多文件合并向导，支持批量添加 PDF 文件。
- **合并次序调整**：在列表中可任意上移、下移调整文件先后拼接顺序。
- **页面切片提取合并**：不仅能合并整个文件，还支持为每个文件指定提取页码范围（例如：第 1 个文件取 `1-3, 5` 页，第 2 个文件取全部）。

### 5. Word 与 PDF 高保真双向互转
- **PDF 导出为 Word (.docx)**：基于 `pdf2docx` 智能排版引擎，精准识别流式段落、标题层级、内嵌图片与数据表格，生成完全可二次编辑的 `.docx`。
- **Word 导入转换为 PDF**：
  - **优先方案**：检测并联动 Windows 系统原生的 Microsoft Word 或 WPS Office 接口，100% 矢量无损导出 PDF；
  - **无环境兜底方案**：若主机未安装 Office 办公软件，系统自动调用纯 Python 解析渲染引擎完成转换，确保任何机器环境均可运行。
- **异步后台执行**：转换过程在后台 `QThread` 线程中运行，界面不卡顿，配有实时百分比进度条与状态说明。

### 6. 现代 Fluent 清爽界面设计
- **浅色与暗色模式无缝切换**：遵循现代 Fluent / Flat 极简扁平视觉规范，提供柔和的高清矢量 SVG 图标与清爽的配色方案。
- **完整撤销/重做 (Undo/Redo)**：支持 `Ctrl+Z` 撤销与 `Ctrl+Y` 重做，操作有迹可循。
- **拖拽即开**：直接将外部 PDF 或 Word 文件拖入软件窗口即可秒速打开或提示转换。

│   └── dialogs/                # 各功能独立向导对话框
│       ├── merge_dialog.py     # 多文件合并向导
│       ├── word_dialog.py      # Word 转换进度对话框
│       ├── watermark_dialog.py # 文本水印配置对话框
│       └── reorder_dialog.py   # 批量页码重排对话框

    ├── test_core.py            # 核心操作测试
    └── test_ui.py              # UI 逻辑集成测试

## 🚀 启动与构建运行

### 1. 源码直接启动
```bash
# 安装依赖
pip install -r requirements.txt

# 启动软件
python app.py
```

### 2. 运行自动化测试套件
```bash
python -m unittest discover -s tests -p "test_*.py"
```

### 3. 编译打包为 Windows .exe
```bash
# 打包为便携式绿色执行目录 (dist/PdfEditor/PdfEditor.exe)
python build_exe.py

# 或者打包为单个独立 EXE 文件
python build_exe.py --onefile
```
打包生成后的 `PdfEditor.exe` 位于 `dist/PdfEditor` 目录中，可直接脱离 Python 环境独立双击运行！
